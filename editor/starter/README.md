# Bunting starter

Publish a distribution as a standalone HTML table with interval labels, counts and meters. Reuse the same bin definitions in reports and tests.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Bunting** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
2
2
2
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/bunting) · [View the release](https://github.com/Rahulchaube1/blyx-bunting/releases/tag/v0.1.0)
